# lotto-lab

로또 6/45 + 연금복권 720+ 데이터 수집·통계 분석·번호 생성 도구.
데이터 출처는 동행복권 공개 API(2026-07 개편판)이며, 수집 → 검증 → 생성 전 과정이 자동화되어 있다.

## 구성

| 파일 | 역할 |
|---|---|
| `lotto_lab.py` | 로컬 실행 버전 (수집 + 분석 + 추천, 전부 포함) |
| `lotto_sheets.gs` | 구글 시트 버전 (Apps Script — 주간 자동실행 트리거 포함) |
| `data/lotto_history.csv` | 로또 전 회차 (번호, 1등 당첨자수, 판매액) |
| `data/pension_history.csv` | 연금복권 720+ 전 회차 |
| `report.md` | 마지막 실행 리포트 |

## 로컬 실행

```
python lotto_lab.py              # 신규 회차 갱신 + 분석 + 추천 5세트
python lotto_lab.py --sets 10    # 추천 10세트
python lotto_lab.py --no-fetch   # 저장 데이터로 분석만
python lotto_lab.py --seed 42    # 재현 가능한 생성
```

필요 패키지: `pandas`, `numpy`, `scipy`, `requests`

## 자동 갱신 (Windows 작업 스케줄러 — 기본 경로)

작업 스케줄러에 `lotto-lab-update` 작업이 등록되어 있다 (2026-07-15 설치):

- **토 21:30** (로또 20:35 추첨 후) / **목 20:30** (연금 19:05 추첨 후) `run_update.cmd` 실행
- PC가 꺼져 있었으면 다음 부팅 때 밀린 실행을 수행 (`StartWhenAvailable`)
- 결과는 `data/*.csv` 갱신 + `report.md` 재생성, 실행 이력은 `logs/update.log`에 누적
- 수동 확인: `schtasks /query /tn lotto-lab-update` / 해제: `schtasks /delete /tn lotto-lab-update /f`

### 시트 구성

| 시트 | 내용 |
|---|---|
| `로또이력` / `연금이력` | 원본 당첨 데이터. 날짜는 `2026-07-18(토)` 형식, 연도가 바뀌는 행에 굵은 구분선 |
| `통계` | 번호별 출현·미출현(색조 그라데이션) + 조합 프로파일 요약 |
| `로또추천` | 회차별 추천 5세트. 회차 그룹마다 배경 교대 + 경계선 |
| `연금추천` | 품절 대비 순위 6건 (조·번호 분리 열) |
| `성적` | 누적 적중 성적표 — 등수별 건수, 맞은 개수 분포를 **이론 기대 건수와 나란히** 비교 |

### 결과 채점 (자동)

추첨 결과가 들어오면 [복권분석 > 결과 채점]이 지난 추천을 자동 채점한다(주간 실행에 포함):

- **로또**: 맞은 번호 칸을 초록, 보너스 일치는 호박색으로 칠하고 `적중`(예: `5개+보너스`)과
  `등수`(1~5등/낙첨)를 기록. 당첨 행은 등수 열이 굵은 초록으로 강조된다.
- **연금**: 뒤에서부터 일치한 자릿수만 초록 굵게 표시(리치텍스트). 등수는 연금복권 규칙대로
  1등(조+6자리) / 2등(6자리) / 3등(뒤5) … 7등(뒤1)으로 판정하고 보너스 번호 일치도 표기.
- 아직 추첨 전인 회차는 회색 `추첨 전`으로 남는다. 이미 채점된 행은 다시 실행해도 결과가 같다.

## 방법론 (요약)

1. **무작위성 검증** — 매 실행마다 카이제곱 검정으로 "출현 빈도가 균등분포와 구별되는가"를
   먼저 확인한다. p>0.05면 핫/콜드 번호는 노이즈라는 뜻이고, 지금까지 항상 그랬다.
2. **프로파일 필터** — 역대 1등 조합의 합계 중앙 90% 구간, 홀수 2~4개, 저구간 2~4개,
   연속쌍 ≤1, 구간 다양성 ≥3 등 "전형적 형태"만 통과. 확률은 동일하나 극단 조합을 배제.
3. **분할 회피 (유일한 실질 엣지)** — 회차별 1등 당첨자 수를 판매량으로 보정해
   조합 인기도 모형을 회귀 적합. 생일범위(1~31) 숫자·정형 패턴이 많을수록 당첨자가
   많다(=상금이 쪼개진다)는 것이 데이터로 확인되므로, 예측 인기도가 낮은 조합을 우선한다.
   **적중 확률이 아니라 "당첨 시 수령액"을 최적화하는 것.**

> ⚠️ 각 추첨은 독립시행이다. 이 도구를 포함한 어떤 방법도 1등 확률(1/8,145,060)을
> 높이지 못한다. 구매는 여유 자금 내에서.
